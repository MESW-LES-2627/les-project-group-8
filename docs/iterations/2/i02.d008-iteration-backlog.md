# Next Iteration

covers frontend and backend together, with tests, PR and review.
The [complete backlog](i02.d003-user-stories.md) contains the wider product scope.

Issues labelled `user-story` deliver exactly one story; issues labelled `epic`
group them. Contracts are agreed up front in
[i02.d007.openapi.yaml](i02.d007.openapi.yaml) so stories can be built in
parallel. Board: [Group 8 — Iteration 2](https://github.com/orgs/MESW-LES-2627/projects/24).

sized from their merged PRs; open stories by analogy to them.
