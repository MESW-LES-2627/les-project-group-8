# AI logs (Iteration 1)

## Multiple choice with n options and dropdowns ([#30](https://github.com/MESW-LES-2627/les-project-group-8/issues/30))

- **Tool:** OpenCode (DeepSeek V4.1 Flash).
- **What we used it for:** executing code tasks for US26, US27, US10 and
  US12 — backend validation and endpoints, the database migration, the SvelteKit
  pages, acceptance tests and documentation updates. The team planned and made
  the product decisions; the assistant implemented what was asked.
- **What the assistant produced:** a `picks` module, a pool detail page,
  dynamic option inputs, radio/dropdown persistence, ordered options, and tests
  mapped to the acceptance criteria. After #28 merged, it also merged `staging`
  into the branch and adapted the flow to the existing login guard.
- **Decisions the team made:** use the current pool as the single
  multiple-choice question until #29; authenticate picks with the #28 login
  guard and derive the participant from the token; allow at most 10 options;
  branch `pedrolunet/multiple-choice-n-options-dropdowns` off `staging` and PR
  back to `staging`; mark US26/US27/US10/US12 done.
- **Assumptions we accepted:** picks are allowed strictly before the deadline;
  changing a pick replaces the row via `UNIQUE (pool_id, user_id)`; a dropdown
  starts with an empty "Select an option"; option order is stored in
  `outcomes.position`; a `user_id` in the pick body is refused like `creator_id`.
- **Corrections we made:** the first `PoolForm` version tripped two
  `state_referenced_locally` warnings; they are intentional and were silenced
  with `svelte-ignore`. The first end-to-end script read a space-separated
  variable with zsh's default splitting, which made a pick request look broken;
  the application itself was fine.
- **How we checked it:** `pytest -q` passes 88 tests (the two RLS integration
  tests skip without the publishable key). `pnpm check` (0 errors/warnings) and
  `pnpm build` pass. A manual SvelteKit → Flask → Supabase run created a
  5-option radio pool and a 5-option dropdown pool, saved and changed picks,
  confirmed the saved option was still selected after reload, and confirmed one
  option is rejected with an inline error and no pool is created.
- **Still to do before the definition of done:** verify the flow on staging and
  get a teammate's PR review. Independent answers to different questions in the
  same pool (#29) remain a follow-up.
