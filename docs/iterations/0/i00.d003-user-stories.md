# User Stories

Iteration 0 is the thin vertical slice: create a user, then create a two-option pool, then see it listed. Each acceptance criterion (AC) has exactly one acceptance test in `backend/tests/acceptance/`. The test name describes the behavior; the number-to-test map is in [i00.d004-testing.md](i00.d004-testing.md).

## US1: Create a user

**As** a friend joining the app, **I want** to create a user with just my name, **so that** the pools I create are shown as mine.

| AC | Given | When | Then |
| :--- | :--- | :--- | :--- |
| 1.1 | a name with surrounding spaces | I create a user | the user is created with a new id and the trimmed name |
| 1.2 | an empty or blank name | I create a user | I get a 400 error and no user is created |
| 1.3 | a name longer than 80 characters | I create a user | I get a 400 error and no user is created |

## US2: Create a two-option pool

**As** a user, **I want** to create a pool with a title, a statement, a deadline and exactly two outcomes, **so that** my friends can predict what will happen.

| AC | Given | When | Then |
| :--- | :--- | :--- | :--- |
| 2.1 | an existing user and valid pool data | I create a pool | the pool is saved as `OPEN`, with me as creator and decider, no winner, and my two outcomes |
| 2.2 | a deadline with a timezone offset | I create a pool | the deadline is stored and returned in UTC |
| 2.3 | a `creator_id` that is not an existing user | I create a pool | I get a 400 error and no pool is created |
| 2.4 | fewer or more than two outcomes, an empty one, or two equal ones | I create a pool | I get a 400 error and no pool is created |
| 2.5 | a deadline that is not in the future | I create a pool | I get a 400 error and no pool is created |
| 2.6 | a deadline that is not a valid ISO-8601 timestamp | I create a pool | I get a 400 error and no pool is created |
| 2.7 | an empty name or statement, or one that is too long (120 / 500) | I create a pool | I get a 400 error and no pool is created |
| 2.8 | a request body that is not JSON | I create a pool | I get a 400 error |

## US3: See the pools

**As** a user, **I want** to see all pools with their current status, newest first, **so that** I know which ones are still open.

| AC | Given | When | Then |
| :--- | :--- | :--- | :--- |
| 3.1 | no pools exist | I list the pools | I get an empty list |
| 3.2 | two pools created one after the other | I list the pools | the newest one comes first |
| 3.3 | a pool whose deadline has passed and has no winner | I list the pools | its status is `LOCKED` |
