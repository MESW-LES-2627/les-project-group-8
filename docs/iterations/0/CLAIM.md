## Vertical Prototype

The Iteration 0 vertical prototype demonstrates the end-to-end pool creation flow: a guest or pre-seeded user creates a prediction pool with two outcomes and a future deadline, and the pool appears on the home page with `OPEN` status. This validates integration between the SvelteKit frontend, Flask backend, and PostgreSQL database. See the [MVP document](https://github.com/MESW-LES-2627/les-project-group-8/blob/635799912a620cf7afe5fadbbfe1a47641003509/docs/iterations/0/i00.d002-mvp.md) for the full specification.
